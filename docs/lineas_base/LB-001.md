# Línea Base LB-001

**Proyecto:** Sistema de Gestión de Ventas para Mini Juguetería

incluyendo los elementos iniciales necesarios para continuar el
desarrollo de forma trazable.

## Elementos no incluidos

### EC-009 Manual de usuario

Estado: En desarrollo.

## Criterios de aprobación

LB-001 se considera aprobada debido a que:

- Los requerimientos iniciales están definidos.
- La arquitectura inicial está documentada.
- Existe una implementación funcional inicial.
- El esquema de datos está definido.
- Existen casos de prueba.
- Los elementos se encuentran identificados en el inventario.
- Los responsables han sido definidos.
