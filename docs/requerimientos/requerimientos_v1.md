# Requerimientos del Sistema de Gestión de Ventas

## RF-001 Registrar producto
El sistema permitirá registrar juguetes indicando:
- código
- nombre
- categoría
- precio
- stock

## RF-002 Registrar venta
El sistema permitirá registrar una venta seleccionando
uno o varios productos.

## RF-003 Actualizar inventario
El sistema descontará automáticamente del stock
los productos vendidos.

## RF-004 Consultar productos
El sistema permitirá consultar los productos disponibles.

## RF-005 Generar total de venta
El sistema calculará el subtotal y total de la venta.
